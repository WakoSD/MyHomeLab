# 001 - Proxmox Node

## Objective

Build the primary virtualization node for the homelab using an HP ProDesk 600 G2 and Proxmox VE.

## Planned Architecture

The HP ProDesk will serve as the primary virtualization host.

```
Internet
   │
Home Network
   │
HP ProDesk 600 G2
   │
Proxmox VE
   ├── VM 1
   ├── VM 2
   └── VM 3
```

The virtual machines and services will be defined as the homelab evolves.

## Goals

* Install Proxmox VE.
* Configure the host's storage.
* Configure network connectivity.
* Verify access to the Proxmox management interface.
* Deploy the first virtual machine.
* Document the configuration and lessons learned.
